# Your Portfolio Website — Beginner Starter

This is a customizable portfolio website inspired by the structure of Varunan's projects website. This starter is original, not a copy of the other site's source code.

## Files
- `index.html`: homepage / introduction
- `projects.html`: project cards with working category filters
- `experience.html`: employment or volunteer experience
- `skills.html`: skills and interests
- `education.html`: education and training
- `styles.css`: appearance and responsive layout
- `script.js`: project filtering

## Preview on your computer
Open this folder in Visual Studio Code. Double-click `index.html` (or right-click and select Open With > your browser). Click the Projects link to see the filters work.

## Change the content
In every `.html` file, replace `YOUR NAME`, `hello@example.com`, and sample descriptions with your details. Edit the colours in `:root` at the very top of `styles.css`. For each project card in `projects.html`, edit its title, description, tags and `data-category` field. Copy an existing `<article class="card project-card">...</article>` block to add new projects. Note that categories in `data-category` should be lowercase (e.g. `research academic`).

## Publish using GitHub Pages
1. Sign up at https://github.com.
2. Click + > New repository.
3. Name it `YOURUSERNAME.github.io` (your exact GitHub username, in lowercase).
4. Set it to Public and create it.
5. Click Add file > Upload files. Upload the CONTENTS of this folder (index.html etc.), not the ZIP file or its outer folder.
6. Click Commit changes.
7. Go to Settings > Pages > Build and deployment > Source: Deploy from a branch.
8. Set branch to `main` and folder to `/(root)`, then Save. If your default branch is named something else, choose that branch instead.
9. Visit https://YOURUSERNAME.github.io after GitHub finishes publishing.

## Important
Before publishing, remove placeholder content, add your correct email/links, and ensure any project descriptions or photos are suitable to share publicly. For clinical or research work, don't post identifiable patient or participant details or confidential documents.
